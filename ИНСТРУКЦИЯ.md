# Пошаговая инструкция

> **by R6AAF**

Коротко: как поставить, как сделать дамп, как выбрать и сменить регион.
Отказ от ответственности — в [README](README.md#отказ-от-ответственности--disclaimer).

---

## 0. Что понадобится

- Радио FTX-1, включено.
- USB-кабель (тот же, что для CAT).
- Python 3.8+ и библиотека `pyserial`.

`pyserial` **устанавливается автоматически при первом запуске**, если его нет:
скрипт сам вызывает `pip install` (при необходимости `--user`, а если pip
недоступен — сначала `ensurepip`). Интернет нужен только в этот первый раз.

Поставить заранее вручную:

```bash
pip install -r requirements.txt
```

Если `pip` не находится, попробуйте `python -m pip install pyserial`.
Отключить автоустановку можно переменной `FTX1_NO_AUTOINSTALL=1`.

## 0.1. Можно вообще без команд

Запустите скрипт без аргументов — откроется меню:

```bash
python ftx1_region.py
```

```
FTX-1: регионы и EEPROM
by R6AAF

  1  info    текущий регион, прошивка, диапазоны
  2  dump    дамп EEPROM (первые 4 КБ, ~50 с)
  3  list    таблица регионов
  4  set     выбрать и записать регион
  5  ports   список COM-портов
  6  lang    сменить язык / change language
  0  выход
```

Введите цифру и Enter. Пункт `4` — это выбор и смена региона: он покажет
таблицу, спросит код, сделает бэкап и попросит ввести `yes`. Пункт `0` —
выход. Всё остальное ниже описано отдельными командами — они делают то же
самое.

### Язык

При первом запуске скрипт спрашивает язык: `1` русский, `2` English, `3` оба
(описания регионов через `\`). Выбор сохраняется в `~/.ftx1_region_lang`.
Пункт `6` в меню меняет язык на лету. Разово, без сохранения:

```bash
python ftx1_region.py --lang en list
```

`--lang ru|en|both` можно ставить до или после команды. Низкоуровневые ошибки
SPR/SPW/ID остаются на английском — это диагностика протокола.

Если порт не определился, укажите его для меню:

```bash
python ftx1_region.py --port COM14
```

## 1. Найдите порт

Подключите радио к компьютеру. В системе появятся два порта Silicon Labs
CP2105:

- `Standard COM Port` — не для CAT;
- `Enhanced COM Port` — **это CAT**.

Запустите:

```bash
python ftx1_region.py ports
```

В строке нужного порта будет пометка `<-- CAT port>`. Запомните номер, например
`COM14`.

Если порт не определился автоматически, добавляйте `--port COM14` к любой
команде:

```bash
python ftx1_region.py info --port COM14
```

---

## 2. Проверьте связь

```bash
python ftx1_region.py info
```

Ожидаемый вывод:

```
порт      : COM14 @ 38400
ID        : ID0840;
прошивка  : VE00113;
регион    : 0x7753  AUS
байты     : 77 53  флаг 00
описание  : Australian band plan, 12 narrow rows \
            австралийский план, 12 узких участков
```

Если вместо этого `no ID reply`:

1. проверьте, что радио включено;
2. проверьте, что выбран порт **Enhanced**;
3. попробуйте другую скорость: `--baud 9600`, `19200`, `115200`.

## 3. Сделайте дамп

Это ваша страховка.

```bash
python ftx1_region.py dump
```

Результат:

```
saved C:\...\ftx1_region_tool\dumps\eeprom_0000_0FFF_20261109_063759.bin (4096 bytes, 0 bad) + ....txt
```

Куда это легло: папка **`dumps`** внутри папки со скриптом
(`ftx1_region_tool\dumps`). Если запускали из другого каталога — всё равно
туда, путь печатается после сохранения. Своё место можно задать через
`--out`:

```bash
python ftx1_region.py dump --out D:\backup\ftx1_eeprom.bin
```

Файл `.bin` — сами данные, `.txt` — паспорт дампа (дата, порт, прошивка, регион,
SHA-256). Сохраните оба в надёжном месте.

Если хотите совсем полный дамп (64 КБ, около 13 минут):

```bash
python ftx1_region.py dump --full --out eeprom_full.bin
```

## 4. Выберите регион

```bash
python ftx1_region.py list
```

```
Регионы FTX-1 (MAIN V01.13)

  ┌────────┬───────────────┬─────────┬────────────────────────────────────────────────────────────────┐
  │ код    │ имя           │ широкий │ описание (EN \ RU)                                             │
  ├────────┼───────────────┼─────────┼────────────────────────────────────────────────────────────────┤
  │ 0x1CB9 │ DEV           │ да      │ widest: 30 kHz - 75 MHz continuous \ самый широкий: 30 кГц -   │
  │        │               │         │ 75 МГц сплошняком                                              │
  ├────────┼───────────────┼─────────┼────────────────────────────────────────────────────────────────┤
  │ 0xB5A7 │ B2(EU)_MC     │ да      │ classic MARS/CAP: 1.8-30 MHz continuous \ классический         │
  │        │               │         │ MARS/CAP: 1.8-30 МГц сплошняком                                │
  └────────┴───────────────┴─────────┴────────────────────────────────────────────────────────────────┘
```

- В колонке `описание` сначала английский текст, потом через `\` русский.
- `широкий = да` — сплошное КВ, то есть то, что обычно называют MARS/CAP.
- Если не уверены — берите **`0xB5A7`**: сплошные 1.8–30 МГц плюс 6 м, 4 м,
  2 м и 70 см.
- `0x1CB9` шире (30 кГц–75 МГц), но за пределами КВ/6 м/2 м/70 см тракт может
  работать плохо.

Подробные диапазоны для каждого кода показывает:

```bash
python ftx1_region.py info
```

(для текущего региона) или таблица в `README.md`.

## 5. Смените регион

Посмотреть, что изменится, ничего не записывая:

```bash
python ftx1_region.py set --dry-run 0xB5A7
```

Выбрать код интерактивно (покажет таблицу и спросит код):

```bash
python ftx1_region.py set
```

Сменить регион:

```bash
python ftx1_region.py set 0xB5A7
```

Скрипт:

1. покажет текущий регион;
2. покажет, что станет;
3. сохранит бэкап в `backups/` рядом со скриптом;
4. спросит подтверждение — введите `yes`;
5. запишет два байта и проверит их чтением.

Пример:

```
порт      : COM14
ID        : ID0840;
сейчас    : 0x7753  AUS
описание  : Australian band plan, 12 narrow rows \ австралийский план, 12 узких участков

станет    : 0xB5A7  B2(EU)_MC
описание  : classic MARS/CAP: 1.8-30 MHz continuous \ классический MARS/CAP: 1.8-30
            МГц сплошняком
  ┌───────────────────────────┐
  │    1.8000 -   30.0000 МГц │
  │   50.0000 -   54.0000 МГц │
  │   70.0000 -   70.5000 МГц │
  │  144.0000 -  148.0000 МГц │
  │  430.0000 -  450.0000 МГц │
  └───────────────────────────┘

автобэкап 0x0000..0x01FF:
  ...
Записать 0xB5A7 в EEPROM 0x0109/0x010A? введите 'yes': yes

ГОТОВО: в EEPROM теперь 0xB5A7 (B2(EU)_MC), флаг 0x00
Выключите и включите радио (полный цикл), затем снова 'info'.
```

---

## 6. Перезагрузите радио

Выключите и включите радио полностью (не просто кнопкой питания в дежурный
режим, если радио так умеет). Затем:

```bash
python ftx1_region.py info
```

Должно быть:

```
регион    : 0xB5A7  B2(EU)_MC
байты     : B5 A7  флаг 00
```

Если регион вернулся к `0x7753` — прошивка восстанавливает его при загрузке.
Тогда нужен другой путь (CH341A и правка дампа), см. README.

---

## 7. Как откатить

Вернуть исходный код (у вас это AUS):

```bash
python ftx1_region.py set 0x7753
```

Или восстановить байты вручную:

```bash
python ftx1_region.py write 0x0109 0x77
python ftx1_region.py write 0x010A 0x53
```

## Частые вопросы

**Нужно ли вскрывать радио?**
Нет. Всё делается по USB через CAT.

**Почему не работает `JP0710;`?**
В FTX-1 обработчик `JP` — заглушка, радио отвечает `?;`. Инструмент использует
`SPR`/`SPW`, которые в прошивке есть.

**После `set` появилось `CAT error: SPR 0x0109 failed`. Регион записался?**
Скорее всего да. В первой версии скрипта это был баг чтения: ответ `SPR`
обрывался по первому байту `0x3B`, а он может быть данными или контрольной
суммой, поэтому поток «разъезжался». Запись при этом уже прошла. Проверьте:

```bash
python ftx1_region.py info
```

Если там нужный код (строка `байты`) — всё в порядке, перезагрузите радио.
В исправленной версии ответ читается ровно 8 байт, добавлены повторные
попытки и проверка бэкапа перед записью; вместо ошибки вы увидите
`write sent, but the readback failed`.

**Это опасно?**
Пишутся два байта в служебную EEPROM, рядом лежит калибровка. Инструмент её не
трогает и делает бэкап перед записью. Но ответственность за последствия — на
владельце.

**Передавать теперь можно везде?**
Нет. Только там, где разрешено вашей лицензией. Смена региона может нарушать
типовое одобрение.

**Сколько идёт дамп?**
Около 12 мс на байт: 4 КБ — примерно 50 секунд, 64 КБ — около 13 минут.

**Где лежат дамп и бэкап?**
В папке со скриптом: `ftx1_region_tool\dumps\` — дампы, `ftx1_region_tool\backups\`
— автобэкапы перед записью. Обе папки создаются сами. Полный путь печатается
после сохранения. В меню (запуск без аргументов) пункт `2` делает дамп в `dumps`.

**Можно ли сменить регион без дампа?**
Технически да, но не надо: `backups/` создаётся автоматически, а полный дамп —
единственная страховка калибровки.
